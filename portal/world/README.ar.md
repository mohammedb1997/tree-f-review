# جولة شجرة العائلة ثلاثية الأبعاد

تجربة مستقلة ببيانات وهمية، متاحة من معاينة البوابة. تستخدم معرّفات الأشخاص وعلاقات الأبوة من مولّد العينات الحالي. تتوزع الفروع على قطاعات بحجم يتناسب مع عدد الأوراق تحت كل فرع. تعرض لوحة الاسم العربية النسب وتفاصيل الشخص وتتيح الانتقال إلى أسلافه.

تتبدل ألوان الأسماء وعلامات الأشخاص حسب القرابة أو الجيل أو الجنس. يميّز وضع القرابة الأب والأجداد والأبناء المباشرين والأحفاد والذرية. يحافظ الإطار الفاتح على وضوح الشخص المحدد، وتعرض البطاقة الاسم الكامل. تشمل العينة أسماء إناث وهمية لتجربة التلوين.

شغّل من جذر مستودع المراجعة:

```powershell
rtk proxy node portal/world/serve.cjs
rtk proxy node --test portal/world/smoke.test.cjs
```

الرابط المحلي `http://127.0.0.1:4191/portal/world/`. يمكن تمرير منفذ آخر إلى أمر التشغيل. الخادم التجريبي يتيح ملفات العرض المحددة فقط ويستمع محليًا. يستعمل الاختبار Playwright وChrome الموجودين في بيئة المشروع.
