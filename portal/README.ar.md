# بوابة حسابات العائلة

## تشغيل التجربة

من جذر مستودع المراجعة، شغّل الأمر التالي باستخدام Node.js 24. تخدم التجربة بيانات وهمية في الذاكرة، وتنتهي بإيقاف العملية.

```powershell
rtk proxy node portal/server.cjs demo
```

افتح `http://127.0.0.1:4178/`. البريد التجريبي `admin@example.test` وكلمة المرور `FamilyDemo-2026`.

1. اختر شخصًا من الشجرة في قسم إدارة الحسابات. تنشئ البوابة رمز حساب وكلمة مرور مؤقتة صالحة لمرة واحدة خلال ٢٤ ساعة.
2. سلّم الرمز وكلمة المرور المؤقتة لصاحب الحساب على انفراد. يفتح صفحة البوابة ويختار «تفعيل دعوة»، ثم يدخل البيانات التي استلمها ويختار كلمة مروره الخاصة.
3. يسجّل الدخول لاحقًا بالرمز نفسه وكلمة مروره الخاصة. لاستعادة الدخول يوقف المدير الحساب ويصدر دعوة بديلة للشخص نفسه. يحتفظ العضو برمزه ويحصل على كلمة مرور مؤقتة جديدة.

تستمر الحسابات السابقة في تسجيل الدخول بمعرّفاتها المعتادة. ويمكن للمدير نقل حساب قديم إلى رمز عائلي بإيقاف الحساب ثم دعوة الشخص نفسه مجددًا.

يرى الأفراد أسماء الشجرة ويعدّل كل حساب اسمه وأسماء ذريته ويضيف أبناءً داخل فرعه. يملك المدير العام إدارة جميع الأسماء والحسابات وتعديل عنوان الشجرة وتنزيل JSON متوافق مع المحرر. عرض الأشخاص يتبع نطاق العرض المعتمد في المشروع.

## عرض الشجرة حيًا

بعد دخول العضو، يظهر موقعه بإطار ذهبي، ويمكنه عرض العائلة أو حصر المخطط في فرع الشخص المحدد. تعرض بطاقة الشخص نسبه وعدد أبنائه وأحفاده. تظهر آخر مقارنة محفوظة عند وجود تعديل، وتُميّز الأسماء المضافة أو المعدّلة في النسخة الجديدة.

يحفظ الخادم حالتي الشجرة قبل آخر تعديل وبعده في معاملة واحدة، ويبثهما للأعضاء المتصلين عبر `/api/live`. عند تشغيله خلف وكيل عكسي استخدم عملية واحدة لهذا الإصدار، واترك الاستجابة المتدفقة دون تخزين مؤقت. يمكن تحديد منفذ مختلف للتجربة بالأمر `rtk proxy node portal/server.cjs demo 4179`.

## عرض الفرع ودعوات البنات

يبدأ حساب العضو في «فرعي». يعرض هذا النطاق العضو وذريته. عند اختيار «الكل» بعد تسجيل الدخول تظهر أسماء البنات ضمن الشجرة، وتبقى الشجرة الرئيسية قسمًا مستقلًا.

يختار الأب «ابنة» في قائمة «الجنس» لإضافتها إلى قسم «بناتي». يستطيع من القسم إنشاء دعوة خاصة لها. بعد التفعيل تفتح الابنة حسابها عند اسمها، وتستطيع اختيار «الكل» للاطلاع على العائلة. يعرض هذا الحساب الأسماء بصلاحية قراءة. تُحفظ سجلات البنات في جدول منفصل، وتبقى خارج المقارنة العامة وملف JSON الإداري. نسخة SQLite الكاملة خاصة بمضيف البوابة.

يمكن للمدير إضافة ابنة باختيار أبيها من الشجرة. يتولى الأب من قسم «بناتي» تصحيح الاسم وإصدار الدعوة وإدارة الاستعادة. عند اختيار «استعادة الدخول» يُطلب تأكيد إنهاء الجلسات الحالية. تبقى هوية الابنة ورمزها كما هما، وتختار كلمة مرور جديدة بعد التفعيل بكلمة مؤقتة جديدة.

## إعداد نسخة محلية دائمة

اختر مسارًا مطلقًا لقاعدة البيانات في مجلد خاص خارج المستودع، وجهّز نسخة JSON من المحرر. يُستورد الملف مرة واحدة إلى قاعدة جديدة، ويبقى ملف المصدر متاحًا مستقلًا.

عيّن `TREEF_DB` للمسار، و`TREEF_ADMIN` للبريد أو الجوال، و`TREEF_ADMIN_PASSWORD` لكلمة مرور المدير وقت التهيئة. نفّذ `rtk proxy node portal/server.cjs init <مسار JSON>`، ثم أزل متغير كلمة المرور وشغّل `rtk proxy node portal/server.cjs`. اسم المستخدم رقم جوال دولي، وتقبل الأرقام السعودية أيضًا بصيغة `05`.

يستمع الخادم على العنوان المحلي. للوصول من أجهزة العائلة يلزم مضيف دائم وعنوان HTTPS. يضبط المضيف `TREEF_ORIGIN` على عنوان HTTPS النهائي ويحافظ الوكيل العكسي على ترويسة `Host`. إعداد استضافة خاصة ونسخ احتياطي لقاعدة البيانات واعتماد الوصول العائلي خطوات تشغيل مستقلة.

## التحقق

```powershell
rtk proxy node --test portal/server.test.cjs
rtk proxy node --test portal/browser.test.cjs
```

فحص المتصفح يستخدم Chrome وPlaywright كما في اختبارات مستودع المراجعة.
